# Campus Event Board – IIIT Vadodara

## Project Description
The Campus Event Board is a responsive web application developed as part of Lab Assignment 6. It displays campus events and provides interactive features using HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Fetch API
- JSON

## Features
- Displays campus events dynamically.
- Filters events using the search feature.
- Responsive layout for desktop and mobile screens.
- Interactive hamburger menu.
- Loads event data from `events.json` using Fetch API.
- Displays loading, success, and error states.
- Includes form validation.

## Project Files
- `index.html` – Main webpage.
- `style.css` – Main stylesheet.
- `script.js` – JavaScript functionality.
- `events.json` – Event data.
- `images/` – Project images and logo.
- `NOTES.pdf` – Assignment answers and screenshots.

## How to Run
1. Open the project folder in VS Code.
2. Run the project using Live Server.
3. Open the webpage in your browser.
